# رياضيات التوجيهي — المستوى المتقدم (جيل 2008)

موقع اختبارات تدريبية على نمط الامتحان الوزاري لمادة الرياضيات (المستوى المتقدم) — حقل العلوم والتكنولوجيا.

## التشغيل

```bash
npm install
npm run dev        # ثم افتح الرابط الذي يظهر (عادة http://localhost:5173)
```

للنسخة النهائية: `npm run build` ثم `npm run preview`.

## النشر

الموقع منشور على GitHub Pages: https://mohammad-mriesh-job.github.io/tawjihi/

كل `push` إلى الفرع `main` يشغّل `.github/workflows/deploy.yml` تلقائيًّا (lint ثم build ثم نشر)، ويمكن تشغيله يدويًّا من تبويب Actions.

**المؤقّت:** زمن كل اختبار = مجموع أزمنة أسئلته (سهل 2.5 د، متوسط 3.5 د، صعب 5 د)، وهو معدّل الامتحان الوزاري
(50 سؤالًا في 180 دقيقة). يُحفظ التقدّم في المتصفح، ويستمر المؤقّت إذا أُغلقت الصفحة.

## التحقق من صحة الأسئلة

الأسئلة مكتوبة في `question-bank/` (Python + sympy)، وكل سؤال يمرّ بثلاثة فحوص قبل أن يصل إلى الموقع:
الإجابة تُحسب بشكل مستقل وتطابق البديل الصحيح فقط، ونص كل بديل يُحلَّل ويُقارَن بقيمته، والصيغ داخل نص السؤال تُحلَّل وتُقارَن
بالمقدار الذي حُسبت منه الإجابة. التفاصيل في [QUALITY.md](QUALITY.md).

بعد تعديل أي سؤال:

```bash
python3 -m venv .venv && .venv/bin/pip install sympy "antlr4-python3-runtime==4.11" matplotlib
cd question-bank && ../.venv/bin/python u3.py   # يولّد src/data/units/u3.ts (والأشكال في public/fig) بعد التحقق
```

لا تعدّل ملفات `src/data/units/*.ts` و `src/data/mocks/s*.ts` يدويًّا — فهي مولّدة (`mock_s1.py` و `mock_s2.py` تولّد النماذج).
